# Data do Modex RP

Este repositório público contém somente a **Data aproveitável do Modex RP**, preparada para o APK `ModexRP.com.br`. Ela deriva da cópia de trabalho separada do backup original e inclui a personalização de modelos/variantes para as skins 163 e 9.

## Download

Use a release [`modexrp-data-2026-11-14`](https://github.com/windsonlins8520/data-do-modex/releases/tag/modexrp-data-2026-11-14), asset `modex.com.br-aproveitavel.zip`. O launcher extrai o conteúdo para o diretório de dados do aplicativo.

**Este repositório não contém o backup original.** O backup continua privado e separado.
